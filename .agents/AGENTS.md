# Project-Scoped Rules for Courier Management

## 1. Next.js API Response Shape Validation
- **Requirement**: All Next.js API routes (under `src/app/api/...`) return wrapped responses in the shape of `{ success: boolean, data?: any, error?: string }`.
- **Constraint**: When parsing API responses in the frontend (such as `src/app/dashboard/...` or `src/components/...`), always expect the response to be wrapped in a `{ success, data }` object. 
- **Action**: Always parse and extract the payload securely. For example:
  ```typescript
  const resJson = await res.json();
  const saved = resJson.data || resJson; // Fallback to handle both wrapped and raw shapes safely
  ```

## 2. Spreadsheet/Grid Row Insertion & IDs
- When saving an inline spreadsheet/grid row, ensure the React state correctly updates both the temporary ID (`tempId`) to the real database ID (`saved.id`) and the autogenerated properties (like `challanNo`). Failure to do this causes key collision bugs and clears out fields.
